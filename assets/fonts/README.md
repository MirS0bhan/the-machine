Fonts bundled for The Machine compositor chrome (HarfRust + FreeType).

Shaping uses [HarfRust](https://github.com/harfbuzz/harfrust) (pure-Rust
HarfBuzz algorithm port). Glyph bitmaps are rasterized with FreeType.

- Inter-Regular.ttf / Inter-Medium.ttf / Inter-Bold.ttf
  Design-system `type.family.default` (see docs/design-system/02-style/03-typography.md).
  SIL Open Font License 1.1 — https://github.com/rsms/inter

- JetBrainsMono-Regular.ttf
  Design-system `type.family.numeric` companion face.
  SIL Open Font License 1.1 — https://www.jetbrains.com/lp/mono/
